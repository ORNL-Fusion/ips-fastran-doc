# Command

```bash
ips.py --simulation=solps_iter.config --platform=$MACHINE_CONFIG --log=ips.log
```

$MACHINE_CONFIG defined in the conda envrionment

# Bash script

```bash
#!/bin/bash -l
module load python
source activate /home/jbp/cesol/v0.12b

ips.py --simulation=solps_iter.config --platform=$MACHINE_CONFIG_SERIAL --log=ips.log 1> ips.out 2> ips.err &
```

`$MACHINE_CONFIG_SERIAL`: ...
