## Problem definition

- **Constraints**: Pnet > 50 MW, fNI = 1
- **Objective**: Find an optimum aspect ratio that minimizes H98

## Design space

| Variable | Description                      | Range      |
| -------- | -------------------------------- | ---------- |
| r        | Major radius [m]                 | 3 ~ 5      |
| aratio   | Aspect ratio                     | 2.5 ~ 3.5  |
| kappa    | Elongation                       | 1.7 ~ 2.0  |
| delta    | Triangularity                    | 0.4 ~ 0.6  |
| bt       | Toroidal field [T]               | 5 ~ 8      |
| q95      | q95                              | 4 ~ 8      |
| fgw_ped  | Pedestal GW density fraction     | 0.7 ~ 1.0  |
| nepeak   | Density peaking                  | 1.5 ~ 2.0  |
| h98      | Traget confinement H98           | 0.9 ~ 1.5  |
| pnb      | NBI injection power [MW]         | 20  ~ 100  |
| enb      | NBI injection energy [keV]       | 500 ~ 1000 |
| prf      | RF power [MW]                    | 20 ~ 100   |
| r_rf     | Location of RF power deposition  | 0 ~ 0.7    |
| rho_jpeak| Location of current profile peak | 0.3 ~ 0.6  |
| jaxis    | Ration of J(0)/Jpeak             | 0.7 ~ 1.2  |
